# Contributing

Thanks for improving firebase-rules-audit.

## Before opening a pull request

1. Keep changes focused on the documented Firebase rules checks or action behavior.
2. Add or update tests that cover the behavior.
3. Run the test suite locally:

```bash
npm test
```

4. Update the README or action metadata when the public interface, inputs, outputs, or behavior changes.

## Reporting issues

Include the smallest Firebase rules example that reproduces the result, the expected severity or outcome, and the actual output. Do not include credentials, private configuration, or production data.
